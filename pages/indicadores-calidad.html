Actualizar datos · cargar Excel o JSON baseline integrado

Formato JSON: mismo shape que el baseline integrado (estructura { meses, meses_full, zonas, cats_order, kpi, proj_global }).
Formato Excel (.xlsx / .xlsm): con hojas META, KPI, ZONAS y PROYECCION pre-agregadas (los .xlsm se leen igual; las macros se ignoran).
Formato CSV: una sola tabla tipo hoja ZONAS — columnas zona,tipo,Ene,Feb,…. El módulo deriva los meses, las categorías y recalcula la proyección automáticamente.
Formato Excel crudo (hoja DATOS): tu documento de trabajo registro por registro. El módulo agrega solo, sumando SAIDI_E / SAIFI_E por mes × zona × causa. Mapeo de columnas: Causa 2 = N, SAIFI_E = AJ, SAIDI_E = AK, ZONA CONFIRMADA = BG; el mes se extrae automáticamente de la columna de fecha. La causa cruda se conserva como categoría y los 3 grupos (Sobrecarga/Deslastre · Racionamiento/Déficit · Otras) se derivan solos.
Varios archivos a la vez: puedes adjuntar dos o más archivos (por ejemplo un .xlsm y un .csv) — se combinan en un solo dataset (los valores no vacíos de cada archivo prevalecen y las categorías se unen por nombre). El archivo se procesa en tu navegador y se guarda localmente (IndexedDB) — no se sube a internet.
