1 · Todo el CSS del módulo vive bajo un prefijo

Ninguna regla del módulo existe fuera de .ftm. Eso hace imposible que el módulo pinte la topbar, el sidebar o cualquier página del sitio, y hace imposible que AQUA le rompa la maquetación interna.

/* ANTES — el módulo suelto: colisiona con .btn, .tabs, .card, table de AQUA */ .btn { background:#0B4F6C; ... } table { border-collapse:collapse; ... } /* DESPUÉS — namespaced: no puede tocar nada fuera de .ftm */ .ftm .ftm-btn { background:var(--ftm-acento); ... } .ftm table.ftm-fleet { border-collapse:collapse; ... } .ftm * { box-sizing:border-box; } /* el reset queda encerrado */

2 · Las variables de AQUA alimentan al componente

El módulo conserva SUS nombres de variable, pero el valor lo entrega AQUA. Es un solo bloque de traducción: si mañana AQUA cambia de tema, el módulo se re-tematiza sin que nadie lo toque.

.ftm { --ftm-petrol: var(--ink-1); /* era #0B4F6C — petróleo del módulo */ --ftm-verde: var(--teal-deep); /* era #1B998B */ --ftm-acento: var(--brand); /* iOS blue de AQUA */ --ftm-line: rgba(0,40,90,.14); --ftm-font: var(--font-sans); /* era 'Quicksand' */ }
