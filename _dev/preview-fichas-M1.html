Punto de conexión

La página no lleva datos dentro. En producción declara window.SGM_DATA_SOURCE y la capa de datos del sitio le entrega la flota; si esa función no existe (como en este preview), el módulo cae a la muestra de demostración rotulada. Ese es el único punto de sutura. 

// pages/fichas-tecnicas.html — al final del <body>
window.SGM_DATA_SOURCE = async function () {
  const m = await import('../assets/js/data/transformadores.js');
  return await m.listarTransformadoresSalud();
  // → listarV2({limite:500})  →  domain/parque_salud.js :: filasParque()
  // Firestore one-shot con limit() — free-tier sagrado, sin onSnapshot.
};
El mapeo de campos de Firestore a las columnas del módulo (UUCC registrada/calculada, nivel, banda de capacidad, condición 1–5) se implementaría como dominio puro y testeable en assets/js/domain/, igual que el resto del proyecto — la página sólo pinta.
